Trees — Binary Tree Traversals
Aug 4, 2025 · 3 min read · 240 words

Overview

Binary tree traversal visits all nodes. Three main types:

  • Inorder (Left → Root → Right) — gives sorted output for BST
  • Preorder (Root → Left → Right) — useful for copying tree
  • Postorder (Left → Right → Root) — useful for deletion

Key Insight

Iterative traversal uses a Stack<TreeNode> to avoid call-stack overflow on deep trees.

Time: O(n) · Space: O(h) where h = height of tree.
